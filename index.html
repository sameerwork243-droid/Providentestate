This site is a Next.js (Node.js) application — it does not use a static index.html like a PHP/WordPress site. The real homepage is generated at runtime by the application server, so the domain only shows the full website once the hosting account runs the Node.js app. Until then, this page is served as the index file.

To go live, the hosting team needs to:

  1. Enable Node.js (cPanel → Software → Setup Node.js App / CloudLinux Node.js selector) on the account.
  2. Create the app with Application root = the folder containing the uploaded project and startup file = server.js.
  3. Run npm install, then npm run build (or upload a pre-built .next folder).
  4. Set environment variables: PROVIDENT_DATABASE_URL, PROVIDENT_ADMIN_EMAIL, PROVIDENT_ADMIN_PASSWORD.
  5. Restart the app — the domain then serves the full website automatically.
